# Kilter Твистер

Игра «Твистер» на подсветке Kilter Board Original 12×12 with kickboard. Веб-приложение для Chrome:
подключается к стене по Bluetooth (Web Bluetooth) без официального приложения и без установки.

**Открыть:** https://dmoskalenko111.github.io/kilterboard_connect/

## Правила

1. На старте горят 4 зацепки цвета 1: две для рук, две для ног.
2. «Дальше» зажигает новую зацепку цветом 2, на экране написано, какой конечностью на неё встать.
3. Следующее «Дальше» гасит освободившуюся зацепку, перекрашивает новую в цвет 1 и зажигает следующую.

Ходы выбираются в пределах досягаемости тела (масштаб задаётся ростом): руки всегда минимум на 35% роста
выше ног, руки не ставятся на кикборд и мелкие зацепки для ног. Одновременно горит не больше 5 зацепок.
Под потолком ходы чаще ведут вниз, чтобы не висеть наверху в скрученной позе.

Игроки: в блоке «Игрок» (над настройками) можно добавить, выбрать, переименовать и удалить игрока. У каждого
игрока свой рост, рекорды и последние игры; остальные настройки общие. «Гость» (175 см) есть всегда и выбран
по умолчанию. Имена хранятся только в браузере телефона.

Счёт: «Сорвался» показывает, сколько ходов вы продержались, и сравнивает с общим рекордом всех игроков на этом уровне
(его же показывает карточка хода и называет голос).
Блок «Рекорды» под настройками показывает общие рекорды (лучший результат среди всех игроков, с именем)
или, по переключателю, рекорды выбранного игрока: рекорд каждого уровня с подробностями (самый трудный отрезок,
угол, рост, дата, включённые «Подъём» / «Перехват» / «Скрещивание») и последние 5 игр; рекорды можно сбросить.
Всё это хранится только в браузере телефона.

Сложность: четыре уровня (лёгкий — хардкор) или «Подробная настройка сложности» — шкала от 1 до 10, где
3, 5, 7 и 9 совпадают с лёгким, средним, сложным и хардкором, 1–2 проще лёгкого, а 10 — труднее хардкора,
на грани возможностей. Под шкалой показан примерный грейд уровня при текущем угле стены.

В настройках также: «Подъём» (ходы ведут вверх
до верха стены и обратно) и «Перехват» (две руки или две ноги на одной зацепке, примерно в 4% ходов; на мелких
зацепках — только с флажком «Разрешить сдваиваться на мелких зацепках»); всё это выключено по умолчанию.

Счёт на стене (Настройки → «Отображать счёт», по умолчанию выключено): число сделанных ходов двумя цифрами
из болт-онов в левом верхнем углу (шрифт 3×5, своим цветом, до 99). На старте и при первом ходе — 00, затем 01, 02…
Игровые зацепки горят поверх счёта; на выбор ходов счёт не влияет.

Оценка грейда: под командой показывается примерный грейд «трассы» из последних 8 ходов по шкале
Font / V, например «Трасса примерно 6b / V4 · угол 30°», а после срыва — самый трудный отрезок игры.
Считается по средним грейдам реальных трасс Kilter на этих зацепках, длине ходов, растяжкам и углу стены
(Настройки → Угол стены). Это ориентир по подобранной вручную формуле, а не измерение.

Озвучка (Настройки → Озвучка: выкл / кратко / подробно, по умолчанию выключена) произносит команды голосом
самого устройства. Используются только русские голоса, работающие без интернета: текст не уходит с телефона.
Если такого голоса нет, на Android его можно скачать: Настройки → Система → Язык и ввод → Синтез речи.

## С телефона

Нужен Android и Chrome (на iPhone Web Bluetooth не работает).

1. Включите Bluetooth и геолокацию (без геолокации Android не ищет Bluetooth-устройства).
2. Откройте ссылку выше в Chrome. Меню ⋮ → «Добавить на главный экран» — появится иконка.
3. Закройте официальное приложение Kilter: к стене подключается только одно устройство.
4. «Мок → Стена» → «Подключить стену» → выберите стену в списке.
5. Сверьте, что на стене горят те же зацепки, что на превью в телефоне.

Без интернета: после первого открытия приложение хранится в телефоне и открывается без сети (Bluetooth
интернет не нужен). Новая версия скачивается сама, когда сеть есть, и включается при следующем запуске
(после полного закрытия приложения); внизу появляется строка с кнопкой «Обновить сейчас». В Chrome можно
выбрать «Установить приложение» — появится иконка, и оно откроется в своём окне.

Режим «Мок» рисует стену на экране и работает без Bluetooth — для проверки игры где угодно.

Если связь со стеной пропадёт, приложение само переподключится в течение минуты и отправит текущий ход: игра не сбрасывается.

## Состав

| Путь | Что это |
| --- | --- |
| `index.html` | Готовое приложение одним файлом (собирается `build.py`) |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | Работа без интернета и установка на телефон; `sw.js` собирается из `src/sw.js` |
| `src/protocol.js` | Протокол Aurora, API 2 и 3: кодировщик, потоковый декодер, нарезка по 20 байт |
| `src/twister.js` | Логика игры без интерфейса и Bluetooth |
| `src/grade.js` | Примерная оценка грейда последних ходов (Font / V) |
| `src/app.html` | Интерфейс, мок и Bluetooth-транспорт |
| `holds.json` | 476 зацепок: `[placement_id, x, y, led, set_id, кикборд]`, координаты в дюймах |
| `emulator/` | Эмулятор стены для Linux: ноутбук притворяется стеной, см. `emulator/README.md` |
| `tools/hold_stats.py` | Статистика зацепок из базы Kilter: как часто каждую берут рукой и ногой (запуск — в начале файла) |
| `data/hand_grades.json` | Грейды зацепок для рук: для каждой — средний грейд реальных трасс, где её берут рукой. Получены `tools/make_grades.py` из локальной статистики `tools/hold_stats.py`; сама статистика в репозиторий не входит |
| `test/` | Тесты: `node test/test.js`, `python3 test/test_emulator_ble.py` и сверка эмулятора с кодировщиком (`test_emulator.py`) |

После правок в `src/` пересоберите: `python3 build.py`.

## Источники

- Разбор протокола: [Philipp Bazun](https://www.bazun.me/blog/kiterboard/), [fake_kilter_board](https://github.com/1-max-1/fake_kilter_board)
- Карта зацепок — общедоступные данные приложения Aurora, выгруженные сообществом, из [hangtime-grip-connect](https://github.com/Stevie-Ray/hangtime-grip-connect)
  (layout 1, размер 10, наборы Bolt Ons и Screw Ons)
- Грейды зацепок — сводка по трассам из базы приложения Kilter Board, полученной через [BoardLib](https://github.com/lemeryfertitta/BoardLib)

**Неофициальный проект.** Он не связан с Kilter, Setter Closet и Aurora Climbing и ими не одобрен.
Данные о стене и трассах принадлежат Aurora Climbing и авторам трасс; Kilter Board — товарный знак его владельцев.
Программа только зажигает зацепки, как официальное приложение; прошивку и настройки контроллера не меняет.
